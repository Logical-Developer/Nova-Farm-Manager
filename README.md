# Nova Farm Manager

A desktop userscript for managing farm lists and attack templates on supported Nova-HB pages.

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/).
2. Open the [Nova Farm Manager installation link](https://raw.githubusercontent.com/Logical-Developer/Nova-Farm-Manager/main/Nova%20Farm%20Manager.user.js).
3. Confirm the installation in Tampermonkey.

Tampermonkey checks for script updates automatically. To update manually, open the script's dashboard and select **Check for userscript updates**.

## Included

- Create, edit, import, export, and organize farm lists from the Rally Point.
- Save a troop template and apply it to selected villages.
- Remove matching coordinates from a selected list using a loss-list JSON file.
